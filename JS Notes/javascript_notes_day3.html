Topic 01
🏷️ Identifiers
Names you give to variables, functions, classes, etc.

WHAT ARE IDENTIFIERS?

Identifiers are names you create to identify variables, functions, classes, objects, or any other user-defined items in your code.

Simple definition: An identifier is any name YOU choose in your program (not a keyword reserved by JavaScript).

EXAMPLES OF IDENTIFIERS

// Variable identifiers
let userName = "Ravi";     ← userName is an identifier
const MAX_SIZE = 100;    ← MAX_SIZE is an identifier
var _privateVar = 42;    ← _privateVar is an identifier

// Function identifiers
function calculateTotal() { } ← calculateTotal is an identifier

// Class identifiers
class User { }                ← User is an identifier

// Object property identifiers
const person = {
  firstName: "Ravi",       ← firstName is an identifier
  age: 25                 ← age is an identifier
};

NAMING RULES FOR IDENTIFIERS

✅ MUST follow these rules:

  • Can contain: letters (a-z, A-Z), digits (0-9), underscore (_), dollar sign ($)
  • MUST start with: letter, underscore (_), or dollar sign ($)
  • CANNOT start with: a digit
  • CANNOT be: a reserved keyword (like let, const, if, for, etc.)
  • Case-sensitive: userName ≠ username ≠ UserName
// ✅ VALID identifiers
let name;
let firstName;
let first_name;
let firstName1;
let $price;
let _private;
let MAX_VALUE;

// ❌ INVALID identifiers
let 1name;        ← cannot start with digit
let first-name;  ← hyphen not allowed
let first name;  ← space not allowed
let class;       ← reserved keyword
let for;         ← reserved keyword

NAMING CONVENTIONS (BEST PRACTICES)

camelCase
For variables and functions
userName, calculateTotal, getData
PascalCase
For classes and constructors
User, ShoppingCart, PaymentService
UPPER_SNAKE_CASE
For constants
MAX_SIZE, API_URL, PI
_leading underscore
For private/internal (convention)
_privateMethod, _internalValue
Pro tip: Choose meaningful, descriptive names. getUserById is better than gubi. Code is read more often than it's written!
Topic 02
💎 Literals
Fixed values written directly in code

WHAT ARE LITERALS?

Literals are fixed values that you write directly in your code. They represent actual data — not variables or expressions.

Simple explanation: A literal is the actual value itself, not a name pointing to a value.

TYPES OF LITERALS

1. NUMBER LITERALS

// Integer literals
42
100
-15

// Decimal literals
3.14
-0.5
2.5e3        ← scientific notation (2500)

// Binary literal (prefix 0b)
0b1010       ← 10 in decimal

// Octal literal (prefix 0o)
0o755        ← 493 in decimal

// Hexadecimal literal (prefix 0x)
0xFF         ← 255 in decimal

// BigInt literal (suffix n)
123456789012345678901234567890n

2. STRING LITERALS

// Single quotes
'Hello'
'Ravi'

// Double quotes
"Hello World"

// Template literals (backticks)
`Hello ${name}`    ← allows expressions inside
`Multi-line
string`

// Escape sequences
"Line 1\nLine 2"   ← \n = newline
"Tab\there"        ← \t = tab
"Quote: \"Hi\""    ← \" = escaped quote

3. BOOLEAN LITERALS

true
false

4. NULL LITERAL

null            ← intentional absence of value

5. UNDEFINED LITERAL

undefined       ← uninitialized variable value

6. ARRAY LITERALS

[1, 2, 3]
['a', 'b', 'c']
[]                ← empty array

7. OBJECT LITERALS

{ name: 'Ravi', age: 25 }
{ x: 10, y: 20 }
{}                ← empty object

8. REGULAR EXPRESSION LITERALS

/abc/           ← regex pattern
/[0-9]+/g      ← with flags

LITERAL vs IDENTIFIER — KEY DIFFERENCE

// Literals (actual values)
42              ← number literal
"Hello"         ← string literal
true            ← boolean literal

// Identifiers (names for values)
let age = 42;         ← 'age' is identifier, 42 is literal
let message = "Hello"; ← 'message' is identifier, "Hello" is literal
let isActive = true;   ← 'isActive' is identifier, true is literal
Topic 03
➕ Operators
Symbols that perform operations on values

WHAT ARE OPERATORS?

Operators are symbols that tell JavaScript to perform specific operations on values (called operands).

Formula: operand1 operator operand2
Example: 5 + 3 → 5 and 3 are operands, + is the operator

1. ARITHMETIC OPERATORS

Perform mathematical calculations

+ (Addition)
5 + 3 → 8
- (Subtraction)
5 - 3 → 2
* (Multiplication)
5 * 3 → 15
/ (Division)
6 / 3 → 2
% (Modulus/Remainder)
7 % 3 → 1 (remainder)
** (Exponentiation)
2 ** 3 → 8 (2³)
++ (Increment)
x++ → x = x + 1
-- (Decrement)
x-- → x = x - 1

2. ASSIGNMENT OPERATORS

Assign values to variables

let x = 10;      ← = (basic assignment)
x += 5;         ← same as: x = x + 5
x -= 3;         ← same as: x = x - 3
x *= 2;         ← same as: x = x * 2
x /= 2;         ← same as: x = x / 2
x %= 3;         ← same as: x = x % 3
x **= 2;        ← same as: x = x ** 2

3. COMPARISON OPERATORS

Compare two values and return true/false

5 == 5          → true (equal value)
5 === 5         → true (equal value AND type)
5 === "5"       → false (different types)
5 != 3          → true (not equal)
5 !== "5"       → true (different type or value)
5 > 3           → true (greater than)
5 < 3           → false (less than)
5 >= 5          → true (greater than or equal)
3 <= 5          → true (less than or equal)
Important: Always use === (strict equality) instead of ==. It checks both value AND type, preventing bugs.

4. LOGICAL OPERATORS

Combine boolean values

// && (AND) — both must be true
true && true    → true
true && false   → false

// || (OR) — at least one must be true
true || false   → true
false || false  → false

// ! (NOT) — inverts boolean
!true           → false
!false          → true

5. STRING OPERATORS

// + (concatenation)
"Hello" + " " + "World"  → "Hello World"
"Age: " + 25             → "Age: 25"

// += (append)
let msg = "Hello";
msg += " World";        → msg is now "Hello World"

6. TERNARY OPERATOR (CONDITIONAL)

// condition ? valueIfTrue : valueIfFalse
let age = 20;
let status = age >= 18 ? "Adult" : "Minor";
// status = "Adult"

7. TYPE OPERATORS

// typeof — returns type of value
typeof 42              → "number"
typeof "Hello"         → "string"
typeof true            → "boolean"
typeof undefined       → "undefined"
typeof null            → "object" (quirk!)

// instanceof — checks if object is instance of class
[] instanceof Array   → true
{} instanceof Object  → true

8. OTHER OPERATORS

// Spread operator (...)
let arr1 = [1, 2];
let arr2 = [...arr1, 3, 4];  → [1, 2, 3, 4]

// Optional chaining (?.)
obj?.property         → safe access, returns undefined if obj is null

// Nullish coalescing (??)
let x = null ?? 10;    → 10 (use 10 if null/undefined)
Topic 04
🔐 Keywords & Reserved Words
Special words reserved by JavaScript — cannot be used as identifiers

WHAT ARE KEYWORDS?

Keywords are reserved words that have special meaning in JavaScript. You CANNOT use them as identifiers (variable names, function names, etc.).

Critical rule: Never use keywords as names. JavaScript will throw a syntax error.

ALL JAVASCRIPT KEYWORDS

These words are reserved and have specific purposes:

break case catch class const continue debugger default delete do else export extends finally for function if import in instanceof let new return super switch this throw try typeof var void while with yield

FUTURE RESERVED WORDS

These might become keywords in future JavaScript versions — avoid using them:

enum, implements, interface, package, private, protected, public, static, await (inside async functions)

SPECIAL VALUES (NOT KEYWORDS BUT RESERVED)

true           ← boolean literal
false          ← boolean literal
null           ← null literal
undefined      ← undefined literal
NaN            ← Not a Number
Infinity       ← Infinite number

KEYWORDS BY CATEGORY

VARIABLE DECLARATION

var, let, const

CONTROL FLOW

if, else, switch, case, default

LOOPS

for, while, do, break, continue

FUNCTIONS

function, return, yield

ERROR HANDLING

try, catch, finally, throw

CLASSES & OBJECTS

class, extends, super, this, new

MODULES

import, export

OPERATORS AS KEYWORDS

typeof, instanceof, delete, void, in

COMMON MISTAKES

// ❌ WRONG — using keyword as identifier
let class = "Math";     ← SyntaxError!
let function = 5;      ← SyntaxError!
let if = true;          ← SyntaxError!

// ✅ CORRECT — use different names
let className = "Math";
let func = 5;
let condition = true;
Topic 05
⚖️ Loose Equality (==) vs Strict Equality (===)
The most important comparison operators — understand the difference!

THE KEY DIFFERENCE

Operator Name Checks Value? Checks Type? Type Coercion?
== Loose Equality ✅ Yes ❌ No ✅ Yes (converts types)
=== Strict Equality ✅ Yes ✅ Yes ❌ No (no conversion)

BASIC EXAMPLES

// == (Loose Equality) — converts types then compares
5 == 5           → true (same value, same type)
5 == "5"         → true (converts "5" to number 5, then compares)
0 == false       → true (false converts to 0)
1 == true        → true (true converts to 1)
"" == false      → true (empty string converts to 0)
null == undefined → true (special case)

// === (Strict Equality) — no conversion, checks value AND type
5 === 5          → true (same value, same type)
5 === "5"        → false (different types: number vs string)
0 === false      → false (different types: number vs boolean)
1 === true       → false (different types: number vs boolean)
"" === false     → false (different types: string vs boolean)
null === undefined → false (different types)

TRICKY INTERVIEW CASES

// Case 1: Arrays and Objects
[] == []          → false (different objects in memory)
[] === []         → false (same reason)
{} == {}          → false (different objects)
{} === {}         → false (same reason)

// Case 2: NaN is never equal to anything (even itself!)
NaN == NaN       → false ⚠️
NaN === NaN      → false ⚠️
isNaN(NaN)       → true (use this to check NaN)

// Case 3: null and undefined
null == undefined  → true (special rule in ==)
null === undefined → false (different types)
null == 0         → false
undefined == 0    → false

// Case 4: String to Number conversion
"10" == 10       → true (string "10" converts to number)
"10" === 10      → false (different types)
" " == 0        → true (space converts to 0)
"\n" == 0       → true (newline converts to 0)

// Case 5: Boolean conversion
true == 1        → true (true converts to 1)
true === 1       → false (different types)
false == 0       → true (false converts to 0)
false === 0      → false (different types)

// Case 6: Empty array/object coercion
[] == 0           → true ([] converts to ""  → 0)
[] == false       → true (same conversion)
[] === 0          → false (different types)

// Case 7: Weird but true!
"0" == false     → true ("0" → 0, false → 0)
"0" === false    → false (different types)
"" == "0"        → false (both strings, different values)

TYPE COERCION RULES FOR ==

When using ==, JavaScript converts types following these rules:

  • String + Number: String converts to Number
  • Boolean + Anything: Boolean converts to Number (true→1, false→0)
  • null == undefined: Always true (special case)
  • Object + Primitive: Object converts to Primitive (valueOf/toString)
  • null/undefined + Anything else: Always false (except null==undefined)
// Examples of coercion:
"5" == 5         → "5" becomes 5 → 5 == 5 → true
true == 1        → true becomes 1 → 1 == 1 → true
"" == 0          → "" becomes 0 → 0 == 0 → true
[] == ""          → [] becomes "" → "" == "" → true
[5] == 5         → [5] becomes "5" → "5" becomes 5 → 5 == 5 → true

REAL INTERVIEW QUESTIONS

QUESTION 1: Predict Output
console.log("1" + 1);         // ?
console.log("1" - 1);         // ?
console.log(true + true);      // ?
console.log(true + "1");      // ?

// Answer:
// "11"  ← + with string = concatenation
// 0     ← - forces number conversion
// 2     ← true + true = 1 + 1 = 2
// "true1" ← + with string = concatenation
QUESTION 2: What prints?
console.log([] == ![]);    // ?

// Answer: true
// Step 1: ![] → false (any object is truthy, ! inverts it)
// Step 2: [] == false
// Step 3: [] converts to "" → 0
// Step 4: false converts to 0
// Step 5: 0 == 0 → true
QUESTION 3: Fix the Bug
// Buggy code:
if (userInput == null) {
  console.log("No input");
}

// Problem: This catches BOTH null and undefined!
// Because null == undefined is true

// Fix 1: Use === for exact check
if (userInput === null) {
  console.log("Exactly null");
}

// Fix 2: Check both null and undefined explicitly
if (userInput == null) {  ← intentional ==
  console.log("null or undefined");
}
Best Practice: ALWAYS use === (strict equality) unless you have a specific reason to use ==. The only acceptable use of == is checking value == null to catch both null and undefined.

Practice JavaScript problems asked in top companies

PROBLEM 1: Reverse a String

Asked by: Google, Amazon, Microsoft

Problem: Write a function to reverse a string without using built-in reverse().

// Solution 1: For loop
function reverseString(str) {
  let result = "";
  for (let i = str.length - 1; i >= 0; i--) {
    result += str[i];
  }
  return result;
}

// Solution 2: Array methods
function reverseString(str) {
  return str.split("").reverse().join("");
}

// Solution 3: Recursion
function reverseString(str) {
  if (str === "") return "";
  return reverseString(str.substr(1)) + str[0];
}

// Test:
console.log(reverseString("hello")); // "olleh"

PROBLEM 2: Check Palindrome

Asked by: Facebook, Amazon

Problem: Check if a string is a palindrome (reads same forwards and backwards).

// Solution 1: Two pointers
function isPalindrome(str) {
  let left = 0;
  let right = str.length - 1;
  
  while (left < right) {
    if (str[left] !== str[right]) {
      return false;
    }
    left++;
    right--;
  }
  return true;
}

// Solution 2: Reverse and compare
function isPalindrome(str) {
  const reversed = str.split("").reverse().join("");
  return str === reversed;
}

// Test:
console.log(isPalindrome("racecar")); // true
console.log(isPalindrome("hello"));   // false

PROBLEM 3: FizzBuzz

Asked by: Almost every company!

Problem: Print numbers 1 to n, but for multiples of 3 print "Fizz", for multiples of 5 print "Buzz", for both print "FizzBuzz".

function fizzBuzz(n) {
  for (let i = 1; i <= n; i++) {
    if (i % 15 === 0) {
      console.log("FizzBuzz");
    } else if (i % 3 === 0) {
      console.log("Fizz");
    } else if (i % 5 === 0) {
      console.log("Buzz");
    } else {
      console.log(i);
    }
  }
}

// Cleaner version:
function fizzBuzz(n) {
  for (let i = 1; i <= n; i++) {
    let output = "";
    if (i % 3 === 0) output += "Fizz";
    if (i % 5 === 0) output += "Buzz";
    console.log(output || i);
  }
}

fizzBuzz(15);
// Output: 1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz

PROBLEM 4: Find Duplicate in Array

Asked by: Amazon, Google

Problem: Find the first duplicate value in an array.

// Solution 1: Using Set
function findDuplicate(arr) {
  const seen = new Set();
  
  for (let num of arr) {
    if (seen.has(num)) {
      return num;
    }
    seen.add(num);
  }
  return null;
}

// Solution 2: Using Object
function findDuplicate(arr) {
  const count = {};
  
  for (let num of arr) {
    if (count[num]) {
      return num;
    }
    count[num] = true;
  }
  return null;
}

// Test:
console.log(findDuplicate([1, 2, 3, 2, 4])); // 2

PROBLEM 5: Sum of Array

Asked by: Microsoft, Apple

Problem: Calculate sum of all numbers in array.

// Solution 1: For loop
function sumArray(arr) {
  let sum = 0;
  for (let i = 0; i < arr.length; i++) {
    sum += arr[i];
  }
  return sum;
}

// Solution 2: reduce()
function sumArray(arr) {
  return arr.reduce((sum, num) => sum + num, 0);
}

// Test:
console.log(sumArray([1, 2, 3, 4, 5])); // 15

PROBLEM 6: Count Vowels

Asked by: TCS, Infosys, Wipro

Problem: Count the number of vowels in a string.

function countVowels(str) {
  const vowels = "aeiouAEIOU";
  let count = 0;
  
  for (let char of str) {
    if (vowels.includes(char)) {
      count++;
    }
  }
  return count;
}

// Alternative with regex:
function countVowels(str) {
  const matches = str.match(/[aeiou]/gi);
  return matches ? matches.length : 0;
}

// Test:
console.log(countVowels("Hello World")); // 3

PROBLEM 7: Factorial

Asked by: Amazon, Accenture

Problem: Calculate factorial of a number (5! = 5×4×3×2×1).

// Solution 1: Iterative
function factorial(n) {
  let result = 1;
  for (let i = 2; i <= n; i++) {
    result *= i;
  }
  return result;
}

// Solution 2: Recursive
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}

// Test:
console.log(factorial(5)); // 120
Topic 07
🎯 Interview Q&A
Master these answers for your interview!
Q: What are identifiers?
Names you give to variables, functions, classes, etc. Must start with letter/underscore/dollar sign, cannot be keywords, and are case-sensitive.
Q: Difference between identifier and literal?
Identifier is a NAME (variable, function). Literal is the ACTUAL VALUE (42, "hello", true). Example: let age = 25 → age is identifier, 25 is literal.
Q: Can identifier start with a number?
No. Identifiers must start with letter, underscore (_), or dollar sign ($). "1name" is invalid, but "name1" is valid.
Q: What are the naming conventions?
camelCase for variables/functions (userName). PascalCase for classes (UserService). UPPER_SNAKE_CASE for constants (MAX_SIZE). _underscore for private (convention).
Q: What are JavaScript literals?
Fixed values written directly in code. Types: Number (42), String ("hello"), Boolean (true/false), null, undefined, Array ([1,2]), Object ({x:1}), RegEx (/abc/).
Q: Difference between == and ===?
== checks value only (type coercion). === checks value AND type (strict). Example: 5 == "5" → true, but 5 === "5" → false. Always prefer ===.
Q: What does typeof null return?
"object" — this is a known JavaScript quirk/bug from early days. null is NOT actually an object, it's a primitive type.
Q: What are keywords?
Reserved words with special meaning in JavaScript. Cannot be used as identifiers. Examples: let, const, if, for, function, class, return, etc.
Q: Can you use "class" as variable name?
No. "class" is a reserved keyword. Using it as identifier causes SyntaxError. Use "className" or similar instead.
Q: What is the ternary operator?
Shorthand for if-else: condition ? valueIfTrue : valueIfFalse. Example: let status = age >= 18 ? "Adult" : "Minor";
Q: Difference between & and &&?
& is bitwise AND (operates on bits). && is logical AND (operates on boolean values). Use && for conditions: if (a && b).
Q: What is the spread operator?
... (three dots) expands an array/object. Example: let arr2 = [...arr1, 4, 5] copies arr1 and adds new elements. Also works for objects.
