Topic 01
🔀 if-else Statement
Execute code based on conditions — the most basic decision-making

SYNTAX

if (condition) {
  // code runs if condition is TRUE
} else {
  // code runs if condition is FALSE
}

BASIC EXAMPLE

let age = 20;

if (age >= 18) {
  console.log("You are an adult");
} else {
  console.log("You are a minor");
}
// Output: "You are an adult"

FLOWCHART

Start ↓ Check condition (age >= 18) ↓ TRUE? ────→ Execute if block → "You are an adult" │ FALSE? ───→ Execute else block → "You are a minor" ↓ End

if WITHOUT else

// else is optional
let score = 85;

if (score >= 90) {
  console.log("Excellent!");
}
// Nothing happens if condition is false

NESTED if-else

let temperature = 30;

if (temperature > 35) {
  console.log("Very hot");
} else {
  if (temperature > 25) {
    console.log("Warm");
  } else {
    console.log("Cool");
  }
}
// Output: "Warm"
Key Point: Condition must be a boolean (true/false). JavaScript converts values to boolean — 0, "", null, undefined, NaN are falsy. Everything else is truthy.
Topic 02
🪜 else-if Ladder
Check multiple conditions in sequence

SYNTAX

if (condition1) {
  // runs if condition1 is TRUE
} else if (condition2) {
  // runs if condition1 is FALSE and condition2 is TRUE
} else if (condition3) {
  // runs if condition1 and condition2 are FALSE, condition3 is TRUE
} else {
  // runs if ALL conditions are FALSE
}

EXAMPLE — GRADE CALCULATOR

let marks = 75;

if (marks >= 90) {
  console.log("Grade: A+");
} else if (marks >= 80) {
  console.log("Grade: A");
} else if (marks >= 70) {
  console.log("Grade: B");
} else if (marks >= 60) {
  console.log("Grade: C");
} else {
  console.log("Grade: Fail");
}
// Output: "Grade: B"

HOW IT WORKS

JavaScript checks conditions from top to bottom and executes the FIRST true block, then exits. Remaining conditions are NOT checked.

let x = 15;

if (x > 10) {
  console.log("A");  ← TRUE, prints "A", STOPS HERE
} else if (x > 5) {
  console.log("B");  ← NOT checked (already found TRUE above)
} else {
  console.log("C");  ← NOT checked
}
// Output: "A"
Important: Once a condition is true, the rest are skipped. Order matters!
Topic 03
❓ Ternary Operator
Shorthand for simple if-else — one line conditional

SYNTAX

// condition ? valueIfTrue : valueIfFalse
let result = condition ? value1 : value2;

EXAMPLE

// Traditional if-else:
let age = 20;
let status;
if (age >= 18) {
  status = "Adult";
} else {
  status = "Minor";
}

// Ternary (same thing, one line):
let status = age >= 18 ? "Adult" : "Minor";
// Output: "Adult"

MORE EXAMPLES

// 1. Even or Odd
let num = 5;
let result = num % 2 === 0 ? "Even" : "Odd";
// result = "Odd"

// 2. Max of two numbers
let a = 10, b = 20;
let max = a > b ? a : b;
// max = 20

// 3. Direct use in console.log
let score = 85;
console.log(score >= 50 ? "Pass" : "Fail");
// Output: "Pass"

NESTED TERNARY (NOT RECOMMENDED)

// Works but hard to read — avoid this
let marks = 75;
let grade = marks >= 90 ? "A" :
            marks >= 80 ? "B" :
            marks >= 70 ? "C" : "Fail";

// Better to use if-else for multiple conditions
When to use: Use ternary for simple, single conditions. For complex logic, stick with if-else for readability.
Topic 04
🔄 Switch Statement
Check one value against multiple cases — cleaner than many if-else

SYNTAX

switch (expression) {
  case value1:
    // code if expression === value1
    break;
  case value2:
    // code if expression === value2
    break;
  default:
    // code if no case matches
}

EXAMPLE — DAY OF WEEK

let day = 3;

switch (day) {
  case 1:
    console.log("Monday");
    break;
  case 2:
    console.log("Tuesday");
    break;
  case 3:
    console.log("Wednesday");
    break;
  case 4:
    console.log("Thursday");
    break;
  case 5:
    console.log("Friday");
    break;
  default:
    console.log("Weekend");
}
// Output: "Wednesday"

⚠️ BREAK IS CRITICAL!

Without break, execution "falls through" to next cases:

let x = 2;

switch (x) {
  case 1:
    console.log("One");
    // NO break!
  case 2:
    console.log("Two");
    // NO break!
  case 3:
    console.log("Three");
    break;
}
// Output:
// "Two"
// "Three"  ← falls through!

GROUPING CASES

let fruit = "apple";

switch (fruit) {
  case "apple":
  case "banana":
  case "orange":
    console.log("Common fruit");
    break;
  case "mango":
  case "lychee":
    console.log("Tropical fruit");
    break;
  default:
    console.log("Unknown fruit");
}
// Output: "Common fruit"

switch vs if-else

Featureswitchif-else
Use caseCheck one value against many optionsComplex conditions
ComparisonUses === (strict equality)Can use any boolean expression
ReadabilityCleaner for many casesBetter for ranges/complex logic
PerformanceSlightly faster for many casesSame for few cases
Remember: switch uses === (strict equality). switch(1) will NOT match case "1".
Topic 05
🔁 for Loop
Repeat code a specific number of times

SYNTAX

for (initialization; condition; increment) {
  // code to repeat
}

PARTS EXPLAINED

for (let i = 0; i < 5; i++) {
     ↑           ↑        ↑
     │           │        └─ Increment (runs after each loop)
     │           └─ Condition (checked before each loop)
     └─ Initialization (runs once at start)
  console.log(i);
}

BASIC EXAMPLE

// Print 1 to 5
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// Output: 1 2 3 4 5

EXECUTION FLOW

Step 1: let i = 0 (initialization — once) Step 2: Check i < 5 (true → continue) Step 3: Execute loop body Step 4: i++ (increment) Step 5: Check i < 5 (true → continue) Step 6: Execute loop body Step 7: i++ ...repeat until condition is false...

COMMON PATTERNS

// 1. Count backwards
for (let i = 5; i >= 1; i--) {
  console.log(i);
}
// Output: 5 4 3 2 1

// 2. Skip numbers (increment by 2)
for (let i = 0; i <= 10; i += 2) {
  console.log(i);
}
// Output: 0 2 4 6 8 10

// 3. Loop through array
let fruits = ["apple", "banana", "orange"];
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
// Output: apple banana orange

// 4. Nested loop (multiplication table)
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 3; j++) {
    console.log(`${i} x ${j} = ${i * j}`);
  }
}
When to use for: When you know exactly how many times to loop (e.g., array length, fixed number).
Topic 06
🔄 while Loop
Repeat while condition is true — when you don't know iteration count

SYNTAX

while (condition) {
  // code repeats while condition is TRUE
}

BASIC EXAMPLE

let i = 1;

while (i <= 5) {
  console.log(i);
  i++;  ← IMPORTANT: update counter or loop runs forever!
}
// Output: 1 2 3 4 5

EXECUTION FLOW

Step 1: Check condition (i <= 5) Step 2: If TRUE → execute body Step 3: Repeat from Step 1 Step 4: If FALSE → exit loop

PRACTICAL EXAMPLES

// 1. User input validation (keep asking until valid)
let password = "";
while (password !== "secret") {
  password = prompt("Enter password:");
}
console.log("Access granted!");

// 2. Sum until reaching target
let sum = 0;
let num = 1;
while (sum < 100) {
  sum += num;
  num++;
}
console.log(`Sum: ${sum}, Numbers added: ${num - 1}`);

// 3. Process array (similar to for)
let arr = [10, 20, 30];
let index = 0;
while (index < arr.length) {
  console.log(arr[index]);
  index++;
}

⚠️ INFINITE LOOP WARNING

// ❌ WRONG — infinite loop (never stops!)
let x = 1;
while (x <= 5) {
  console.log(x);
  // Forgot to increment x — loops forever!
}

// ✅ CORRECT — loop ends
let x = 1;
while (x <= 5) {
  console.log(x);
  x++;  ← MUST update counter!
}
When to use while: When you don't know how many iterations needed (e.g., user input, searching, waiting for condition).
Topic 07
🔁 do-while Loop
Execute at least once, then repeat while condition is true

SYNTAX

do {
  // code runs at least ONCE
} while (condition);

KEY DIFFERENCE FROM while

while Loop
let x = 10;
while (x < 5) {
  console.log(x);
}
// Runs 0 times
// (condition false at start)
do-while Loop
let x = 10;
do {
  console.log(x);
} while (x < 5);
// Runs 1 time
// (executes before checking)

EXECUTION FLOW

Step 1: Execute body (ALWAYS runs once) Step 2: Check condition Step 3: If TRUE → go to Step 1 Step 4: If FALSE → exit loop

PRACTICAL EXAMPLE

// Perfect for menu systems — show menu at least once
let choice;
do {
  console.log("1. Start Game");
  console.log("2. Settings");
  console.log("3. Exit");
  choice = parseInt(prompt("Enter choice:"));
} while (choice < 1 || choice > 3);

console.log(`You selected option ${choice}`);

MORE EXAMPLES

// 1. Print 1 to 5
let i = 1;
do {
  console.log(i);
  i++;
} while (i <= 5);
// Output: 1 2 3 4 5

// 2. Dice roll until 6
let dice;
do {
  dice = Math.floor(Math.random() * 6) + 1;
  console.log(`Rolled: ${dice}`);
} while (dice !== 6);
console.log("Got a 6!");
When to use do-while: When you need to execute the loop body AT LEAST ONCE (e.g., show menu, input validation, game loops).
Topic 08
⏸️ break & continue
Control loop execution — exit early or skip iterations

break — EXIT THE LOOP

break immediately exits the loop completely.

// Stop when finding target number
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    console.log("Found 5! Exiting...");
    break;  ← exits loop immediately
  }
  console.log(i);
}
// Output: 1 2 3 4 "Found 5! Exiting..."

continue — SKIP CURRENT ITERATION

continue skips the rest of current iteration and moves to next.

// Print only odd numbers
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) {
    continue;  ← skip even numbers
  }
  console.log(i);
}
// Output: 1 3 5 7 9

COMPARISON

break
for (let i = 1; i <= 5; i++) {
  if (i === 3) break;
  console.log(i);
}
// Output: 1 2
// (exits at 3)
continue
for (let i = 1; i <= 5; i++) {
  if (i === 3) continue;
  console.log(i);
}
// Output: 1 2 4 5
// (skips 3)

PRACTICAL EXAMPLES

// 1. Search in array (break)
let users = ["Alice", "Bob", "Charlie"];
let found = false;

for (let i = 0; i < users.length; i++) {
  if (users[i] === "Bob") {
    console.log("User found!");
    found = true;
    break;  ← no need to check remaining
  }
}

// 2. Skip invalid data (continue)
let scores = [85, -5, 92, 0, 78];
let total = 0;

for (let score of scores) {
  if (score < 0 || score > 100) {
    continue;  ← skip invalid scores
  }
  total += score;
}
console.log(`Total: ${total}`); // 255

WITH NESTED LOOPS

// break only exits innermost loop
for (let i = 1; i <= 3; i++) {
  console.log(`Outer: ${i}`);
  for (let j = 1; j <= 3; j++) {
    if (j === 2) break;  ← breaks inner loop only
    console.log(`  Inner: ${j}`);
  }
}
// Output:
// Outer: 1
//   Inner: 1
// Outer: 2
//   Inner: 1
// Outer: 3
//   Inner: 1

BROWSER ENGINE (The Complete Application)

The Browser Engine is the ENTIRE browser — everything you see and interact with.

// Components of Browser Engine:
Browser Engine (Full Application)
│
├── User Interface (tabs, address bar, bookmarks)
├── Browser Process (main control)
├── Networking (downloads, HTTP requests)
├── Security (HTTPS, permissions, sandboxing)
├── Storage (cookies, localStorage, cache)
├── Extensions/Plugins
└── Rendering Engine ← One component inside!
      └── JavaScript Engine ← Another component!

Examples of Browser Engines:

  • Google Chrome (entire browser)
  • Mozilla Firefox (entire browser)
  • Safari (entire browser)
  • Microsoft Edge (entire browser)

RENDERING ENGINE (The Display Component)

The Rendering Engine is a COMPONENT inside the browser that takes HTML, CSS, JavaScript and displays the webpage.

      ↓
Rendering Engine

3. Combine    → Render Tree

5. Paint      → Draw pixels
      ↓
Webpage appears on screen!

HOW THEY WORK TOGETHER

When you visit a website:

STEP 1: Browser Engine Processes Request

User types "google.com"
   ↓
Browser Engine processes request
   ↓
Networking component fetches HTML/CSS/JS

STEP 2: Rendering Engine Displays Page

HTML/CSS files received
   ↓
Rendering Engine (Blink/WebKit/Gecko)
   ↓
Parses → Layouts → Paints
   ↓
Page appears on screen

STEP 3: JavaScript Engine Runs Code

JavaScript files received
   ↓
JavaScript Engine (V8/SpiderMonkey)
   ↓
Executes code → Updates page dynamically

Topic 10
🎯 Interview Q&A
Common questions on conditionals and loops
Q: Difference between if-else and switch?
if-else can handle complex conditions and ranges. switch is cleaner for checking one value against multiple exact matches. switch uses === (strict equality).
Q: What happens if you forget break in switch?
Fall-through occurs — execution continues to next case even if it doesn't match. This is usually a bug unless intentional for grouping cases.
Q: Difference between for and while?
for is best when you know iteration count (e.g., loop 10 times). while is for unknown iterations (e.g., until user enters valid input). Both can do the same thing.
Q: Difference between while and do-while?
while checks condition BEFORE executing (may run 0 times). do-while executes FIRST, then checks (runs at least once). Use do-while for menus, prompts.
Q: What does break do?
Immediately exits the current loop completely. Commonly used to stop searching once target is found or when condition is met early.
Q: What does continue do?
Skips the rest of current iteration and jumps to next iteration. Used to skip invalid data, even numbers, or unwanted cases.
Q: Can you use break in if statement?
No. break only works inside loops (for, while, do-while) and switch statements. Using it in if alone causes error.
Q: What's the ternary operator?
Shorthand for if-else: condition ? valueIfTrue : valueIfFalse. Example: let status = age >= 18 ? "Adult" : "Minor". Use for simple conditions only.
Q: Infinite loop — what is it?
A loop that never ends because the condition never becomes false. Usually caused by forgetting to update the counter. Must force-quit program.
Q: Can you nest loops?
Yes. Common for 2D arrays, patterns, multiplication tables. Outer loop runs once, inner loop runs completely each time. Time complexity becomes O(n²).
