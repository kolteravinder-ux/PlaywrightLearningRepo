Identifiers

Definition

What is an Identifier?

An identifier is a name given to a variable, function, class, or label. It acts as a unique tag that lets JavaScript reference a value or block of code by name.

Naming Conventions

Common Styles

camelCase — variables & functions
PascalCase — classes & constructors
UPPER_SNAKE_CASE — constants
_prefix — private/internal convention

  • ✔ Must start with a letter, underscore _, or dollar sign $
  • ✔ Can contain letters, digits, underscores, and dollar signs
  • ✘ Cannot start with a digit — 1name is invalid
  • ✘ Cannot contain spaces or special characters (except _ and $)
  • ✘ Cannot be a reserved keyword — e.g. let, class, return
  • ✔ Case-sensitive: myVar ≠ MyVar ≠ MYVAR
// ✔ Valid identifiers
let userName = "Alice";
const _privateVal = 42;
let $price = 9.99;
function calculateTotal() {}

// ✘ Invalid identifiers
// let 1stPlace = "gold";   → starts with digit
// let my-name = "Bob";     → contains hyphen
// let class = "JS";        → reserved keyword
02

Literals

Number

Numeric Literal

Integer, float, hex, octal, binary, BigInt. Examples: 42, 3.14, 0xFF, 0b1010, 9n

String

String Literal

Sequence of characters in single ', double ", or backtick quotes. Backtick enables template literals.

Boolean

Boolean Literal

Only two values: true or false. Used in conditions and logical expressions.

Null / Undefined

Null & Undefined

null — intentional absence of a value.
undefined — variable declared but not assigned.

Object / Array

Object & Array Literal

Inline object: {} or { key: value }.
Inline array: [] or [1, 2, 3].

RegExp

RegExp Literal

Pattern between slashes for matching strings. Example: /\d+/g matches one or more digits globally.

// Number literals
let age  = 25;
let pi   = 3.14159;
let hex  = 0xFF;       // 255
let bin  = 0b1010;    // 10
let big  = 9007199254740991n;

// String literals
let name = 'Alice';
let msg  = `Hello, ${name}!`;   // Template literal

// Boolean literal
let isActive = true;

// Null / Undefined
let x = null;
let y;             // undefined

// Object & Array
const user   = { name: "Bob", age: 30 };
const colors = ["red", "green", "blue"];

// RegExp literal
const pattern = /\d+/g;

DEEP DIVE

Loose ( == ) vs Strict ( === ) Comparison

Loose Equality ==

Type Coercion Happens

JavaScript converts operands to the same type before comparing. Leads to surprising results — generally avoid in production code.

Strict Equality ===

No Type Coercion

Compares both value AND type. No conversion happens. This is the recommended approach in all modern JS code.

// ─── LOOSE EQUALITY ( == ) — type coercion examples ───────────
5         ==  "5"          // true  — number "5" coerced to number 5
0         ==  false        // true  — false coerced to 0
1         ==  true         // true  — true coerced to 1
""        ==  false        // true  — empty string is falsy → 0
"0"       ==  false        // true  — "0" → 0, false → 0
null      ==  undefined    // true  — special rule, only these two
null      ==  0            // false — null only == undefined
NaN       ==  NaN          // false — NaN is never equal to itself
[]        ==  false        // true  — [] → "" → 0, false → 0
[]        ==  0            // true  — [] → "" → 0
[1]       ==  1            // true  — [1] → "1" → 1

// ─── STRICT EQUALITY ( === ) — no coercion ────────────────────
5         === "5"          // false — different types (number vs string)
0         === false        // false — different types (number vs boolean)
1         === true         // false — different types
""        === false        // false — different types
null      === undefined    // false — different types
null      === null         // true  — same type and value
undefined === undefined    // true
5         === 5            // true  — same type and value
"hello"   === "hello"      // true
NaN       === NaN          // false — NaN is never equal (use Number.isNaN)

// ─── LOOSE INEQUALITY ( != ) vs STRICT ( !== ) ────────────────
5  !=  "5"   // false — they ARE loosely equal
5  !== "5"   // true  — different types, strictly NOT equal
EXAMPLES

All Operator Categories with Examples

// ─── ARITHMETIC ───────────────────────────────────────────────
10 + 3    // 13  — addition
10 - 3    // 7   — subtraction
10 * 3    // 30  — multiplication
10 / 3    // 3.333… — division
10 % 3    // 1   — modulus (remainder)
2  ** 8   // 256 — exponentiation
"Hi" + " JS"  // "Hi JS" — string concatenation with +

// ─── ASSIGNMENT ───────────────────────────────────────────────
let x = 10;
x += 5;   // x = 15
x -= 3;   // x = 12
x *= 2;   // x = 24
x /= 4;   // x = 6
x %= 4;   // x = 2
x **= 3;  // x = 8

// ─── RELATIONAL ───────────────────────────────────────────────
5 >  3    // true
5 <  3    // false
5 >= 5    // true
5 <= 4    // false

// ─── LOGICAL ──────────────────────────────────────────────────
true  && false        // false — AND: both must be true
true  || false        // true  — OR: at least one true
!true                  // false — NOT: inverts boolean
null  ?? "default"   // "default" — nullish coalescing
0     ?? "default"   // 0 — 0 is NOT null/undefined
0     || "default"   // "default" — 0 is falsy, || triggers

// ─── UNARY ────────────────────────────────────────────────────
typeof 42           // "number"
typeof "hello"      // "string"
typeof true         // "boolean"
typeof undefined    // "undefined"
typeof null         // "object" ← famous JS quirk!
typeof {}           // "object"
typeof []           // "object" ← arrays are objects
typeof function(){} // "function"

let n = 5;
n++;  // post-increment → n = 6
++n;  // pre-increment  → n = 7
n--;  // post-decrement → n = 6
-n;   // unary minus    → -6
+"42";  // 42 — converts string to number

// ─── BITWISE ──────────────────────────────────────────────────
5 &  3   // 1   — AND  (0101 & 0011 = 0001)
5 |  3   // 7   — OR   (0101 | 0011 = 0111)
5 ^  3   // 6   — XOR  (0101 ^ 0011 = 0110)
~5       // -6  — NOT  (bitwise complement)
5 << 1  // 10  — left shift (5 * 2)
5 >> 1  // 2   — right shift (5 / 2)

// ─── TERNARY ──────────────────────────────────────────────────
const age = 20;
const status = age >= 18 ? "adult" : "minor";  // "adult"
const score = 45;
const grade = score >= 90 ? "A" : score >= 60 ? "B" : "F"; // "F"

// ─── SPREAD & REST ────────────────────────────────────────────
const a = [1, 2], b = [3, 4];
const merged = [...a, ...b];          // [1, 2, 3, 4]
const copy   = { ...{ x:1 }, y:2 };  // { x:1, y:2 }
function sum(...nums) {              // rest param
  return nums.reduce((a,b) => a+b, 0);
}
sum(1, 2, 3, 4);   // 10

// ─── instanceof / in ──────────────────────────────────────────
const arr = [1, 2, 3];
arr instanceof Array   // true
arr instanceof Object  // true — arrays are objects
"name" in { name: "Alice" }  // true
0 in ["a", "b"]             // true — index 0 exists

// ─── OPTIONAL CHAINING & NULLISH ASSIGNMENT ───────────────────
const user = { profile: { city: "Pune" } };
user?.profile?.city    // "Pune"
user?.address?.city   // undefined (no error thrown)

let config = null;
config ??= "default";  // config = "default" (was null)
let flag = false;
flag ||= true;          // flag = true (was falsy)
let val = true;
val &&= false;           // val = false (was truthy)

DECLARATION

var · let · const

// var — function-scoped, hoisted to top of function
var count = 0;
if (true) { var count = 99; }  // same variable! leaks out of block
console.log(count);               // 99

// let — block-scoped, not re-declarable in same scope
let score = 10;
if (true) { let score = 99; }   // different variable inside block
console.log(score);               // 10 — outer unchanged

// const — block-scoped, must be initialized, cannot be reassigned
const PI = 3.14159;
// PI = 3; → TypeError: Assignment to constant variable
const user = { name: "Alice" };
user.name = "Bob";               // ✔ object properties CAN change
// user = {}; → TypeError: re-assignment blocked
CONTROL FLOW

if · else · switch · for · while · do · break · continue · return · try · catch · finally · throw

// if / else
const age = 18;
if (age >= 18) {
  console.log("Adult");
} else if (age >= 13) {
  console.log("Teen");
} else {
  console.log("Child");
}

// switch / case / default / break
const day = "Mon";
switch (day) {
  case "Mon": console.log("Monday"); break;
  case "Fri": console.log("Friday"); break;
  default:   console.log("Other day");
}

// for loop / break / continue
for (let i = 0; i < 5; i++) {
  if (i === 2) continue;  // skip 2
  if (i === 4) break;     // stop at 4
  console.log(i);           // 0, 1, 3
}

// for...of (iterates values)
const fruits = ["apple", "mango", "banana"];
for (const fruit of fruits) { console.log(fruit); }

// for...in (iterates keys)
const obj = { a:1, b:2 };
for (const key in obj) { console.log(key, obj[key]); }

// while / do...while
let n = 0;
while (n < 3) { console.log(n++); }   // 0 1 2
do { console.log(n++); } while (n < 1);  // runs at least once

// try / catch / finally / throw
try {
  throw new Error("Something went wrong!");
} catch (err) {
  console.log(err.message);  // "Something went wrong!"
} finally {
  console.log("Always runs");
}

// return — exits function and sends value back
function add(a, b) { return a + b; }
add(3, 4);  // 7
FUNCTION

function · arguments · yield

// function declaration
function greet(name) { return `Hello, ${name}`; }

// function expression
const square = function(n) { return n * n; };

// arrow function (no own `arguments` or `this`)
const double = (n) => n * 2;

// arguments — array-like object inside regular functions
function showArgs() {
  console.log(arguments[0], arguments.length);
}
showArgs("a", "b", "c");  // "a", 3

// yield — pauses a generator function
function* counter() {
  yield 1;
  yield 2;
  yield 3;
}
const gen = counter();
gen.next().value;  // 1
gen.next().value;  // 2
CLASS / OOP

class · extends · super · this · new · static

// class · constructor · this · new
class Animal {
  constructor(name) {
    this.name = name;    // `this` refers to the instance
  }
  speak() {
    return `${this.name} makes a sound.`;
  }
  static kingdom() { return "Animalia"; }  // static — no instance needed
}

// extends · super
class Dog extends Animal {
  constructor(name, breed) {
    super(name);          // calls Animal's constructor
    this.breed = breed;
  }
  speak() {
    return `${this.name} barks!`;
  }
}

const d = new Dog("Rex", "Labrador");
d.speak();             // "Rex barks!"
Animal.kingdom();      // "Animalia" — static method
ASYNC

async · await

// async — marks a function as asynchronous (returns a Promise)
async function getUser(id) {
  // await — pauses execution until the Promise resolves
  const res  = await fetch(`/api/users/${id}`);
  const data = await res.json();
  return data;
}

// async arrow function
const fetchPosts = async () => {
  try {
    const res = await fetch("/api/posts");
    return await res.json();
  } catch (err) {
    console.error("Fetch failed:", err);
  }
};

// async always returns a Promise
async function hello() { return "world"; }
hello().then(console.log);  // "world"
MISC

import · export · typeof · instanceof · in · of · delete · void · debugger

// import / export / from — ES Modules
// math.js
export const PI = 3.14;
export function add(a, b) { return a + b; }
export default function multiply(a, b) { return a * b; }

// main.js
import multiply, { PI, add } from "./math.js";
import * as Math from "./math.js";  // import everything

// typeof — returns a string describing the type
typeof 42           // "number"
typeof "hello"      // "string"
typeof true         // "boolean"
typeof undefined    // "undefined"
typeof null         // "object" ← historic JS bug
typeof {}           // "object"
typeof function(){} // "function"
typeof Symbol()     // "symbol"
typeof 9n           // "bigint"

// instanceof — checks prototype chain
[] instanceof Array    // true
[] instanceof Object   // true
"hi" instanceof String // false — primitives aren't instances

// in — checks if a property exists in an object
"name" in { name: "Alice" }   // true
"age"  in { name: "Alice" }   // false
0      in ["a", "b"]           // true — index 0 exists

// of — used in for...of to iterate values
for (const ch of "JS") { console.log(ch); }  // "J" "S"
for (const [k, v] of Object.entries({ a:1 })) { console.log(k, v); }

// delete — removes a property from an object
const person = { name: "Bob", age: 30 };
delete person.age;
console.log(person);  // { name: "Bob" }

// void — evaluates expression and returns undefined
void 0              // undefined
void console.log("hi")  // logs "hi", returns undefined

// debugger — pauses code in browser devtools
function buggy() {
  debugger;  // execution pauses here in DevTools
  return 42;
}

🧩 Quick Summary

Identifiers are names you create — follow the rules and naming conventions.
Literals are raw, fixed values written directly in code — numbers, strings, arrays, objects, and more.
Operators perform actions on values — arithmetic, comparison, logical, and modern additions like ?? and ?..
Keywords are reserved words with built-in meaning — you cannot use them as identifiers.
